# logo-design skill

Skill thiết kế **logo / brand-mark** bằng SVG hình học sạch, dùng cho Claude Code (và AI agent khác).
Dẫn trọn quy trình: brief → concept → dựng SVG (đen trước) → tinh chỉnh quang học → test
(16px · 1 màu · đảo nền · shelf test) → trình bày → xuất biến thể + guideline.

## Cài / dùng
- Copy `skills/logo-design/SKILL.md` vào `.claude/skills/logo-design/` của dự án, hoặc cài như plugin
  (`.claude-plugin/plugin.json`).
- Kích hoạt tự động khi bạn nói: "làm logo", "thiết kế thương hiệu", "app icon", "favicon", "redesign logo"…

## Nội dung
- `skills/logo-design/SKILL.md` — toàn bộ phương pháp (tự chứa, không cần thư viện ngoài).
